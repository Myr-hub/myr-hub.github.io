# 七星棋牌技术文档

可直接发布到 GitHub Pages 的静态网站，无需安装依赖或构建。

上传本目录中的 `index.html`、`article.html`、`guide.html`、`style.css`、`favicon.svg` 和 `.nojekyll` 到网站仓库的发布目录。

在仓库 Settings → Pages 中选择 Deploy from a branch，并指定分支和 /(root)。部署完成后访问 Pages 页面显示的网址。

网站名称暂定为“七星棋牌技术文档”。文章为通用写作与网站发布指南，不代表任何游戏源码已经过功能或部署验证。

添加文章时，复制 article.html 为新文件，修改 title、description、正文及导航，然后在 index.html 增加对应文章链接。
