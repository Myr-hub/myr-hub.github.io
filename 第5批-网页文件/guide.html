02 / PUBLISHING

把第一篇文章发布到 GitHub Pages

首页是入口，文章是内容。把两者放进同一个网站，用链接连接起来。

认识这几个文件

  • index.html：访客打开网站时看到的首页。
  • article.html：开篇文章，可以作为后续文章的排版参考。
  • guide.html：你正在阅读的发布指南。
  • style.css 和 favicon.svg：页面样式与网站图标。

准备网站仓库

个人网站通常使用 用户名.github.io 作为仓库名称，对应网址为 https://用户名.github.io/。如果使用普通项目仓库，网站地址通常会包含仓库名称。

上传网站文件

将网站文件放入准备发布的仓库中，让 index.html 位于所选发布目录的最外层。这个版本使用相对链接，可以适配个人网站和带仓库名称的项目网站。

配置 Pages

在仓库的 Settings → Pages 中选择从分支发布（Deploy from a branch），选择存放网页的分支和根目录 /(root)，保存。等部署完成后，在 Pages 页面打开网站地址。

具体可用选项取决于仓库与账号设置。如果仓库已经配置了其他部署方式，请先核对现有设置。

检查访问效果

打开首页，逐个点击文章链接；再用手机检查文字、导航和按钮。后续发布新文章时，可以复制文章页面，修改标题和正文，然后在首页添加对应链接。

更多细节请参考 GitHub 官方建站说明。
